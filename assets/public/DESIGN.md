# AI Chat 前端设计规范 (Design System)

本文档总结了 `assets/public` 下新版前端界面的设计语言与规范，旨在保持极简、优雅且以内容为中心的视觉体验。

## 1. 设计理念 (Philosophy)

*   **极简主义 (Minimalism)**：去除一切不必要的装饰，只保留核心功能元素。
*   **黑白单色 (Monochrome)**：使用纯黑 (`#000`)、纯白 (`#fff`) 以及灰度阶梯，营造专业、冷静的氛围。
*   **内容优先 (Content-First)**：UI 服务于对话内容，减少对阅读的干扰。
*   **流畅交互 (Fluid Interaction)**：强调状态切换的平滑过渡（Fade in/out, Slide）。

## 2. 配色方案 (Color Palette)

基于 Tailwind CSS 默认调色板，主要使用 `Gray` (Cool Gray) 系列。

| 角色 | 色值/类名 | 说明 |
| :--- | :--- | :--- |
| **主色 (Primary)** | `bg-black` / `text-black` | 核心操作按钮、用户头像、强调文字 |
| **背景 (Background)** | `bg-white` | 主内容区域、卡片背景 |
| **次级背景 (Surface)** | `bg-gray-50` (`#f9fafb`) | 侧边栏、输入框背景、代码块背景 |
| **边框 (Border)** | `border-gray-200` (`#e5e7eb`) | 分割线、输入框边框 |
| **主文本 (Text Main)** | `text-gray-900` (`#111827`) | 正文、标题 |
| **次文本 (Text Sub)** | `text-gray-500` (`#6b7280`) | 说明文字、时间戳、占位符 |
| **错误 (Error)** | `text-red-500` / `bg-red-500` | 错误提示、Toast 警告 |

## 3. 排版 (Typography)

*   **字体栈**：`Inter`, `-apple-system`, `BlinkMacSystemFont`, `sans-serif`。优先使用系统字体，保持原生感。
*   **字号**：
    *   正文：`text-sm` (14px) 或 `0.9375rem` (15px) - 提升阅读舒适度。
    *   标题：`text-lg` / `text-xl` / `text-2xl` - 适度加粗 (`font-semibold` / `font-bold`)。
    *   辅助：`text-xs` (12px) - 标签、元数据。

## 4. 组件规范 (Components)

### 4.1 按钮 (Buttons)
*   **主按钮**：黑色背景，白色文字，圆角 `rounded-lg`，Hover 时变浅黑 (`bg-gray-800`)，点击缩放 (`active:scale-95`)。
*   **次级按钮/图标按钮**：透明背景，灰色图标，Hover 时背景变灰 (`hover:bg-gray-100`)。

### 4.2 输入框 (Inputs)
*   **样式**：浅灰背景 (`bg-gray-50`)，极细边框 (`border-gray-200`)。
*   **状态**：Focus 时产生黑色光晕 (`ring-black/5`) 和黑色边框 (`border-black`)，强调当前输入状态。

### 4.3 消息气泡 (Chat Bubbles)
*   **用户 (User)**：
    *   背景：纯黑 (`bg-black`)。
    *   文字：纯白 (`text-white`)。
    *   圆角：`rounded-2xl`，右下角直角 (`rounded-br-sm`) 以指示方向。
*   **AI (Assistant)**：
    *   背景：无背景 / 透明。
    *   文字：默认灰黑 (`text-gray-900`)。
    *   排版：使用 `prose` (Typography 插件) 渲染 Markdown，代码块背景为浅灰。

### 4.4 思考过程 (Reasoning/Thinking)
*   **形态**：可折叠的 `<details>` 标签。
*   **样式**：左侧灰色竖线 (`border-l-2`)，文字灰色 (`text-gray-500`)，旨在与正文区分，不喧宾夺主。

## 5. 布局结构 (Layout)

*   **响应式侧边栏**：
    *   Desktop: 固定宽度 `w-72`，左侧停靠。
    *   Mobile: 默认隐藏 (`-translate-x-full`)，点击汉堡菜单滑出，带遮罩层。
*   **主聊天区**：
    *   Flex 列布局，`flex-1` 撑满剩余空间。
    *   消息列表：`overflow-y-auto`，底部留白 (`pb-32`) 防止被输入框遮挡。
    *   输入框：绝对定位/固定在底部，背景渐变透明 (`bg-gradient-to-t`) 制造悬浮感。

## 6. 交互与动画 (Interaction & Animation)

*   **Toast 通知**：右上角滑入，3秒后滑出。
*   **流式响应**：AI 回复时实时渲染，打字机效果（可选）。
*   **加载状态**：简单的脉冲文字 (`animate-pulse`) 或微型 Loading 动画。
*   **过渡**：通用 `transition-all duration-300`，使 Hover、Focus、显示/隐藏 更加自然。
